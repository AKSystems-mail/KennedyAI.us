# Frontend Design

This skill guides the creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. It prioritizes bold design thinking and meticulous execution.

## Workflow

1.  **Understand the Context**: Identify the purpose, audience, and technical constraints.
2.  **Commit to an Aesthetic**: Choose a bold direction (e.g., brutally minimal, retro-futuristic, editorial).
3.  **Consult Guidelines**: Reference [references/guidelines.md](references/guidelines.md) for detailed aesthetic pillars (Typography, Color, Motion, etc.).
4.  **Execute with Precision**: Implement production-grade code that is visually striking and meticulously refined.

## Core Design Principles

- **Typography**: Choose beautiful, unique, and characterful fonts. Pair a distinctive display font with a refined body font.
- **Color**: Use cohesive palettes with dominant colors and sharp accents.
- **Motion**: Focus on high-impact moments like page-load reveals and scroll-triggered animations.
- **Layout**: Experiment with asymmetry, overlap, and grid-breaking elements.
- **Atmosphere**: Use textures (noise, grain), gradient meshes, and layered transparencies to create depth.

For a detailed breakdown of design pillars and anti-patterns, see [references/guidelines.md](references/guidelines.md).
